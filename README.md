Student Management System

A simple Student Management System built using Python.

 Features

- Add student details
- Enter marks for different subjects
- Calculate total marks
- Calculate percentage
- Calculate grade
- Show PASS / FAIL result
- Display complete student result

 Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops
- Conditional Statements

 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

python student_management.py

Example

The program takes student information and marks as input and displays:

- Student Name
- Roll Number
- Subject-wise Marks
- Total Marks
- Percentage
- Grade
- Result
